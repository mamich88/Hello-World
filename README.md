# Hello World

Este es mi primer archivo `README.md` en GitHub.

## Objetivos del Proyecto

- Aprender a usar Git
- Familiarizarse con GitHub
- Crear un repositorio y gestionar versiones

## Instalación

1. Clona este repositorio:
    ```sh
    git clone https://github.com/mamich88/Hello-World.git
    ```
2. Navega al directorio del proyecto:
    ```sh
    cd Hello-World
    ```
